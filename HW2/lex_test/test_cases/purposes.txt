# COP 3402 Systems Software - HW2 test case purposes
#
# One line per case in test_cases/cases.txt, in the same order: the case name,
# a TAB, and the scenario that case exists to cover. Every case covers a
# scenario no other case covers. The autograder prints this line when a case
# fails, so the report says what the case was checking and not only that it
# did not match.
#
# generate_expected_results.sh refuses to finish when a case here has no case
# in the manifest, or a case in the manifest has no line here.
